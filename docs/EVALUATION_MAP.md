# Evaluation Mapping

## Innovation & Originality — 25%
- Explainable recommendations instead of generic search.
- Related-skill mapping helps when wording differs.
- Student-facing “why this matches” layer builds trust.

## Technical Implementation & Architecture — 30%
- Browser client + Node API + persistence.
- Matching engine separated from HTTP handlers.
- REST endpoints support both student and recruiter workflows.

## UI / UX — 25%
- Role switcher mirrors the two-sided marketplace.
- Visual score breakdown reduces cognitive load.
- Seeded demo supports a fast judging walkthrough.

## Feasibility & Impact — 20%
- Lightweight architecture for low-cost rollout.
- Clear upgrade path to Postgres, authentication, embeddings and analytics.
- Direct SDG 8 alignment through better entry-level opportunity discovery.
