# 3-minute judging demo

### 0:00 — Problem
Students have skills but internships are fragmented and hard to prioritize. Organizations have requirements but receive noisy applicant pools.

### 0:25 — Product
“SkillBridge creates a structured student profile and turns internship requirements into explainable compatibility scores.”

### 0:55 — Student view
Show the seeded profile, top opportunities, then expand a recommendation to show the score breakdown and reasons.

### 1:35 — Profile update
Change a skill or interest, save, and show the ranking change.

### 2:00 — Organization view
Publish an internship with skills/interests, return to Student mode, and show the new opportunity entering the ranking.

### 2:30 — Technical close
Explain the six signals: exact skills, related skills, interests, experience, mode, and text similarity.

### 2:50 — SDG 8
“By connecting demonstrated student skills to suitable entry-level opportunities, the platform reduces search friction and supports access to decent work.”
